## Описание проекта

Проект представляет собой компактный LED-дисплей с микроконтроллером ESP32, выполненный в стиле ретрофутуризма. Устройство отображает полезную информацию (время, температура и др.), подключается по Wi-Fi и Bluetooth, поддерживает настройку яркости, цветовой гаммы и шаблонов.

Основная цель проекта — снизить информационную перегрузку пользователя, предоставляя важные данные без использования телефона или компьютера.

## Используемые компоненты

- LED матрица 64×32
- Микроконтроллер ESP32
- Датчик температуры и влажности (например, DHT11/22 или аналог)
- Блок питания (адаптер или трансформатор)
- Печатная плата (самодельная, фрезерованная)
- 3D-печатный корпус

## Технологии и инструменты

- Arduino (прошивка ESP32)
- КОМПАС-3D (проектирование корпуса)
- 3D-принтер
- GitHub (хранение кода и макетов)
- C++ (при необходимости визуализации/обработки)
- QR-код генератор для GitHub-ссылки

## Установка и запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/your_username/smart_display.git
   ```
2. Загрузите прошивку на ESP32 через Arduino IDE.
3. Подключите устройство к Wi-Fi
4. Дисплей автоматически начнет отображение.


## Сборка устройства

Для правильного подключения LED-матрицы 64×32 к микроконтроллеру ESP32, используйте следующие GPIO пины на плате:

- **GPIO 22** — Красный верхний (R1)
- **GPIO 23** — Зелёный верхний (G1)
- **GPIO 21** — Синий верхний (B1)
- **GPIO 19** — Красный нижний (R2)
- **GPIO 18** — Зелёный нижний (G2)
- **GPIO 26** — Синий нижний (B2)

Адресные линии:
- **GPIO 25** — Линия A
- **GPIO 17** — Линия B
- **GPIO 33** — Линия C
- **GPIO 16** — Линия D
- **GPIO -1** — Линия E (не используется в 64×32 панелях, только для 64×64 панелей)

Дополнительные пины для управления:
- **GPIO 4** — Latch
- **GPIO 14** — Output Enable (OE)
- **GPIO 32** — Clock (CLK)

Эти пины нужно использовать при подключении LED-матрицы к ESP32. Убедитесь, что все соединения выполнены правильно перед загрузкой прошивки.

- Спаяйте все элементы на фрезерованной плате.
- Распечатайте корпус и соберите устройство.
- Поместите все внутрь корпуса и подключите питание.
